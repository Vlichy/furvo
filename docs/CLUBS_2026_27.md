## Crear o verificar las plantillas

~~~powershell
dotnet run --file tools/BuildAdjustedWorld.cs -- data/initial-world-2026-27.v4.db data/initial-world-2026-27.v3.db
~~~

La tarea histórica de VS Code **Crear/verificar plantillas iniciales v3** conserva su destino anterior; para v4 se utiliza el comando de arriba. Si ya existe, comprueba identidad y contenido sin escribir. No sobrescribe partidas ni publicaciones. La utilidad histórica de clubes sigue disponible para destinos nuevos, pero no actualiza el SQLite v2 de esquema 3: la biblioteca actual requiere esquema 4 para operar su mundo, mediante copia explícita cuando corresponda.

Véase [informe de plantillas](SQUADS_2026_27.md). Los nombres de clubes siguen siendo propuestas pendientes de revisión de marcas. No se añaden escudos, logotipos, economía ni simulación.
